# โปรแกรมคำนวณระดับด้วยวิธี H.I.

ไฟล์นี้เป็นเว็บ HTML แบบ Static สามารถเผยแพร่ผ่าน GitHub Pages ได้โดยตรง

## วิธีเผยแพร่บน GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลดไฟล์ `index.html`
3. ไปที่ `Settings`
4. เลือก `Pages`
5. ในส่วน `Build and deployment` เลือก `Deploy from a branch`
6. เลือก Branch เป็น `main` และ Folder เป็น `/root`
7. กด `Save`
8. รอประมาณ 1-3 นาที แล้วเปิดลิงก์ที่ GitHub แสดง

ไม่ต้องใช้ R หรือ Shiny Server เพราะไฟล์นี้ทำงานด้วย HTML, CSS และ JavaScript ในเบราว์เซอร์
